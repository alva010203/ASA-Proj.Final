Proxy Reverso Apache

O serviço de proxy reverso Apache atua roteando os serviços internos, como aplicações WordPress, para o proxy reverso principal, o Traefik. Essa arquitetura permite centralizar o gerenciamento de rotas e facilita o controle de tráfego entre os serviços. A segurança da comunicação é garantida por meio de um certificado SSL autoassinado, que permite o uso de HTTPS, protegendo os dados transmitidos mesmo em ambientes fechados ou de desenvolvimento.
