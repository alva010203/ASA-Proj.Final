Proxy Reverso Nginx

O serviço de proxy reverso Nginx atua roteando as aplicações web internas para o proxy reverso principal, o Traefik. Essa arquitetura permite centralizar o gerenciamento de rotas e facilita o controle de tráfego entre os serviços. A segurança da comunicação é garantida por meio de um certificado SSL autoassinado, que permite o uso de HTTPS, protegendo os dados transmitidos mesmo em ambientes fechados ou de desenvolvimento.

Como proxy reverso, o Nginx atua como um intermediário entre os clientes e os servidores de backend, melhorando a segurança, desempenho e confiabilidade das aplicações web.
